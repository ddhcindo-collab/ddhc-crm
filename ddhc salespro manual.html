A2. 菲傭庫 / 印傭庫 / 黑名單

  • 左側欄：菲傭庫、印傭庫分開兩頁；黑名單係獨立頁，只顯示被標記 ⚠ BLACKLIST 嘅工人（黑名單工人會自動喺菲傭/印傭庫隱藏）。
  • 搜尋：可搜工人編號（HKID/護照）、英文名、暱稱。
  • 篩選器：狀態（Find Job / Have Job / Not finding / Need follow up）、工人類別（GOOD / BEST / NO GOOD）、技能標籤（16 個）、西方星座（Aquarius…Capricorn）、中國生肖（Monkey…Goat）。
  • 新增/編輯工人：填英文名（Full Name）、Ref Number、生日（系統自動顯示星座＋生肖）、五個經驗年數（星馬/台灣中國/中東/香港/其他）、完成合約次數、香港號碼＋印尼/菲律賓號碼、三個日期（Visa 到期 / Termination / 開始搵工日期）、技能 chip（撳一下綠色/取消）。

  • 個人紀錄：眼睛按鈕 → 輸出「個人紀錄 Personal Information」（格式同嘉勝網站 /profile/{id} 一致：個人紀錄／家庭背景／工作經驗／工作記錄／一般諮詢）；可勾「顯示敏感欄位」先印出 HKID／護照；工具列有「編輯工作記錄」按鈕。

A8. 會員登入系統（Admin 專用）

💡 取代舊「員工管理」：帳戶改以 電郵 做唯一識別碼，角色只有兩種 —— Admin（管理員） 與 Member（普通會員）。密碼經 SHA-256 ＋ per-member salt ＋ 800 輪雜湊，明文絕不儲存於 DB 或匯出 JSON。
1️⃣ 用 Admin 帳戶登入 → 左欄「系統設定・會員」。
2️⃣ Admin 開戶：填電郵 / 姓名 / 手機 / 部門 / 緊急聯絡人 / 權限（Admin 或 Member）；密碼可留空 ＝ 會員首次登入時自行設定。
3️⃣ 會員自行註冊：登入閘門「註冊」分頁 → 填電郵＋密碼＋完整會員檔案 → 自動批准、即刻可用。
4️⃣ 擁有權：Member 只可新增及修改「自己經手」的記錄（helpers / employers 的 ownerEmail ＝ 自己）；Admin 可改全部。無法改他人擁有的記錄。
5️⃣ 停用 / 啟用 / 改角色 / 重設密碼 / 改聯絡資料：管理頁操作；停用後該會員不能再登入。系統至少保留一個 Admin。
普通 Member 登入時，「會員管理」頁只顯示唯讀名單，無法新增／停用／改密碼。

Part B · AI 技術與架構手冊（AI 人工智能必讀）

給 AI 的指令：如果工作階段(context)或檔案丟失，先完整閱讀本部分再動手。修改任何代碼前必須遵守 B9 修改守則。禁止重新由零建立系統 —— 只可喺現有檔案上漸進修改。

B1. 系統架構總覽

  • 主程式 + 兩個 companion 檔：ddhc salespro crm v2.5.html（主程式，約 3,000+ 行）＋ crm-data.js（I18N／字典／對照表／知識庫，只放資料）＋ crm-auth.js（會員登入系統）。三個檔必須放同一資料夾，crm-data.js 與 crm-auth.js 經相對路徑 <script src> 載入。無框架、無 build step（只有 Tailwind CDN 與 Lucide Icons 兩個 <script src>）。⚠ CDN 被擋／離線時必須仍可操作：Tailwind 用 typeof tailwind !== 'undefined' 防護；Lucide 用 refreshIcons()（內含 try/catch + __lucideFallback() 文字替代）。絕對唔可以直接呼叫 lucide.createIcons() —— 佢一 throw 就會令 render 函式中斷，之後嘅事件綁定全部漏做（表單按鈕「冇反應」＝用戶見到嘅「閃退」）。
  • 資料單一真相 = 記憶體 DB 物件，修改後經 saveDraft() 寫入 localStorage['wb_crm_draft']。唔直接改 DOM 資料。

• undoSnapshot() —— 只存業務欄位；Undo 堆疊總量封頂 2MB
• autoBackup() —— 3 份自動備份總量封頂 1.5MB
• saveDraft() 最後會清走 Undo + 備份再試一次；仍然失敗就彈紅色警告叫用戶立即匯出 JSON

B12.2 解析器三層比對（parseSurveyReply）

層規則範例
① 題號^(\d{1,2})\s*[.、．。\)\)：:－\-–—]\s*(.*)$ → 查 SURVEY_QUESTIONS 嘅 n12. 1990-03-20
